# 🌷 Dia das Mães

Projeto acadêmico desenvolvido durante o **1º semestre de Ciência da Computação**, na disciplina de **Aplicações para Internet**.

A proposta consiste na criação de uma página web interativa em homenagem ao Dia das Mães, permitindo que o usuário visualize mensagens especiais, personalize um cartão comemorativo e acompanhe uma contagem regressiva para a data.

## 💻 Sobre o projeto

O projeto foi desenvolvido com o objetivo de colocar em prática os primeiros conhecimentos de desenvolvimento web, explorando a estruturação de páginas, estilização de elementos e implementação de interatividade com JavaScript.

A página apresenta uma interface simples e intuitiva, com uma temática visual voltada à celebração do Dia das Mães.

## ✨ Funcionalidades

- **Mensagens especiais:** exibe diferentes mensagens comemorativas a cada clique, alternando entre as opções disponíveis.
- **Gerador de cartão:** permite informar o nome da mãe e o nome de quem está criando a homenagem, gerando uma mensagem personalizada.
- **Contagem regressiva:** calcula automaticamente quantos dias faltam para o próximo Dia das Mães, considerando o segundo domingo de maio.
- **Interface adaptável:** estrutura visual preparada para diferentes tamanhos de tela.
- **Tema automático:** adapta as cores da página de acordo com a preferência de aparência do dispositivo (claro ou escuro).

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização, cores, tipografia e organização dos elementos.
- **JavaScript:** implementação das funcionalidades interativas, manipulação do DOM e cálculos da contagem regressiva.

## 🚀 Como executar

O projeto não necessita de instalação de dependências ou configuração de servidor.

1. Faça o download ou clone este repositório.
2. Localize o arquivo `dia-das-maes.html`.
3. Abra o arquivo em qualquer navegador de internet.
4. Interaja com as funcionalidades disponíveis na página.

## 📚 Contexto acadêmico

Este projeto representa uma das minhas primeiras experiências práticas com desenvolvimento web durante a graduação em Ciência da Computação.

A atividade contribuiu para a compreensão dos fundamentos de HTML, CSS e JavaScript, além de proporcionar contato inicial com conceitos de interatividade e manipulação de elementos em páginas web.
